# 404 — Seite nicht gefunden

Overrides `MASTER.md` for the ClubSite not-found experience.

## Intent

Empty-state recovery: clear status, one primary escape, a few secondary club destinations. No dead-end.

## Layout

1. Soft navy→paper atmosphere (gradient / subtle pitch accent) — not a flat white void
2. Brand signal: large display “404” + short German headline
3. One supporting sentence
4. CTA group: Startseite (primary) + Suche
5. Secondary destinations: Mannschaften, Presse, Mitglied werden (text links, not cards)

## Tokens

Use MASTER tokens only (`navy`, `pitch`, `paper`, `line`, `ink`). Do **not** introduce sports-red / Bebas Neue from generic sports palettes.

## Motion

- `Reveal` with `immediate` on hero copy (LCP-safe)
- `Stagger` / `StaggerItem` on secondary links (~0.05s)
- Respect `prefers-reduced-motion` via existing motion helpers

## A11y

- Single `h1`
- Status context via eyebrow + heading (no emoji icons)
- `min-h-11` targets, visible `focus-visible` rings
- `noindex` is automatic for 404 responses

## Copy (DE)

- Eyebrow: `404`
- Headline: `Seite nicht gefunden`
- Lead: `Diese Adresse gibt es bei uns nicht — vielleicht ein alter Link oder ein Tippfehler.`
- Primary: `Zur Startseite`
- Secondary: `Suche`
